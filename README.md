# VD Commons

영상디자인학과 동기들이 공지, 스터디, 비교과, 공모전, 전시회, Q&A를 메타버스형 캔버스에서 공유하는 순수 HTML/CSS/JavaScript 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 설치나 서버가 필요 없습니다.

## 포함된 기능

- 이름, 학년, 학번, 나이, 세부전공 입력
- 학년 제한이 있는 월드 목록
- 3D 도트형 동물 캐릭터 10종과 간단한 장신구 커스터마이징
- 2D 또는 아이소메트릭 캔버스 월드 생성
- 방향키를 누르고 있는 동안 부드럽게 이어지는 캐릭터 이동
- 선택/붓그리기/픽셀 지우개/획 지우개 도구
- 레이아웃 블럭 추가, 드래그 이동, 크기 조절, 폰트 크기 조절, 3D 면 부착
- 일정 취합, 비교과 추천, 스터디 모집, 전시회 관람팟, Q&A 블럭
- 댓글/참여 버튼
- 이미지 드래그 앤 드롭
- 캐릭터 옆 채팅 말풍선과 화면 가장자리 말풍선

## 배포

GitHub Pages에는 이 폴더의 `index.html`, `styles.css`, `app.js`를 그대로 올리면 됩니다.
